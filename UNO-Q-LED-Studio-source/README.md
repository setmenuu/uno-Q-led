# UNO Q LED Studio

설치 없이 사용하는 13×8 LED 그림·애니메이션 편집기입니다.

## 사용하기

압축 파일을 풀고 `dist/index.html`을 Chrome 또는 Edge에서 열면 사용할 수 있습니다. 별도로 제공된 `UNO-Q-LED-Studio.html`은 모든 기능이 하나의 파일에 들어 있어 단독으로 열 수 있습니다. 설치나 인터넷 연결은 필요하지 않습니다. 브라우저에 따라 로컬 파일의 자동 저장이 제한될 수 있으므로 중요한 작업은 **프로젝트 저장**으로 내려받으세요.

1. 격자에 그림을 그리거나 **이미지 가져오기**로 PNG·JPG·WebP를 선택합니다.
2. 여러 이미지를 선택하면 각각을 새로운 프레임으로 추가합니다. 단일 이미지는 현재 프레임을 교체하거나 새 프레임에 추가할 수 있습니다.
3. **전체 보이기** 또는 **화면 채우기**, 확대·가로·세로 위치를 조절합니다. **켜기·끄기** 모드에서 변환 기준을 조절할 수 있습니다. 투명한 부분은 꺼집니다.
4. 프레임을 추가·복제·삭제·앞뒤로 이동하고 표시 시간을 지정합니다.
5. 재생으로 확인하고 **App Lab 코드**에서 복사하거나 `sketch.ino`를 내려받습니다.
6. Arduino App Lab에서 UNO Q용 새 앱을 만들고 `sketch/sketch.ino` 내용을 생성 코드로 교체한 뒤 **Run**을 누릅니다.

## 편집과 저장

- 펜으로 같은 밝기 칸을 누르면 꺼집니다. 지우개는 항상 끕니다.
- 실행 취소: Ctrl/Command+Z. 다시 실행: Ctrl/Command+Shift+Z.
- **이전 프레임 겹쳐 보기**를 켜면 직전 프레임을 흐린 테두리로 보여줍니다. 이 표시 자체는 생성 코드에 포함되지 않습니다.
- 프로젝트 저장: Ctrl/Command+S. JSON 파일을 **프로젝트 열기**로 다시 엽니다.
- 최대 200프레임, 프레임별 20~60000ms. 속도는 0.5×·1×·2×·4×입니다.
- 8단계 밝기를 켜기·끄기로 바꾸면 밝기 4 이상은 켜집니다. 실행 취소로 복원할 수 있습니다.
- 반복을 끄면 마지막 프레임을 표시한 채 멈춥니다.
- 이미지 처리는 브라우저 안에서 수행합니다. 이미지를 서버로 전송하지 않습니다.
- PNG·JPG·WebP 정지 이미지를 지원합니다. GIF 자동 분해는 포함하지 않습니다.

## 생성 코드

Arduino 공식 UNO Q 예제의 `Arduino_LED_Matrix`·`setGrayscaleBits()`·`draw()`를 사용합니다. 픽셀은 왼쪽 위부터 가로로 13개씩 총 104개입니다. 애니메이션은 `millis()` 기반이며, 내보낸 코드에는 반복과 속도 설정도 반영됩니다.

실제 보드의 LED 밝기와 화면의 밝기는 차이가 있을 수 있습니다. 보드 연결 및 업로드는 Arduino App Lab에서 수행합니다. 실제 UNO Q 보드에서의 컴파일·실행 검증은 수행하지 않았습니다.

확인한 항목: 픽셀 편집·프레임 복제·실행 취소, 투명 PNG 변환과 네 모서리 위치, 반복 없는 재생 종료, 프로젝트 저장·불러오기, 밝기 모드별 코드 생성, 배열의 픽셀 순서·속도 설정·잘못된 프로젝트 거부, 단독 HTML의 스크립트 문법과 외부 자산 의존성 제거.

현재 환경에서 웹 게시에 필요한 하위 프로세스 실행이 제한되어, 온라인 게시 주소는 제공하지 않습니다.

공식 문서: https://docs.arduino.cc/tutorials/uno-q/user-manual/
